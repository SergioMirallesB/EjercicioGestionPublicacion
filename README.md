# EjercicioGestionPublicacion
Repositorio del "Equipo A" por parte de Sergio Miralles B.

## Juego: La 5ª pared
Juego de terror psicológico en el que somos una joven con un trastorno grave, o eso es lo que dicen todos los médicos.
A lo largo del juego descubrirá la verdad de su supuesta "enfermedad".

## Cómo colaboramos
El equipo realiza reuniones rutinarias de avances para tener las velocidades y las metas actualizadas.
Cada uno trabaja de forma telemática, y una vez al mes se hace una reunión presencial con inversores para mostrar los avances del proyecto y recibir directrices.
